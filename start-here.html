Emailed to the cohort 1–2 weeks before Workshop 1 as their first assignment. Work the checklist, then prove it in Verify & Submit at the bottom. Check items off as you complete them — your progress is saved in this browser. Step-by-step help for every item lives in the Setup Guides.

0 / 5 complete

  • 1 · Terminal check

    macOS/Linux: open Terminal. Windows: open PowerShell — Windows 10/11 ships an SSH client built in, so you do not need WSL or PuTTY. Run ssh -V; any version is fine.

    proof: ssh -V output — auto-checked in Verify & Submit below
  • 2 · GitHub account created, with your @colorado.edu email linked

    Professional username; personal email as primary (accounts outlive .edu addresses); add your @colorado.edu address in Settings → Emails — it links you to the cohort and unlocks free GitHub Education benefits.

    proof: username auto-checked in Verify & Submit below
  • 3 · Duo two-factor working on your IdentiKey

    You'll log into the workshop server with your IdentiKey credentials, and Duo is how CU trusts that account — plus it's required for CU services generally.

    proof: successful Duo push
  • 4 · Laptop with admin rights + charger

    Every workshop is hands-on. A laptop you can install software on — not an iPad.

    proof: just bring it
  • 5 · Optional · CU VPN (Cisco Secure Client) — for off-campus work later

    On the campus network (CU Secure WiFi) you won't need it, workshop included. Off campus, the workshop server is unreachable without it — so install it when you want to work from home: OIT's install instructions, server vpn.colorado.edu. Not a prerequisite for the workshop.

    proof: none needed — tick it when you've done it

Server access is automatic. BIT has set up a dedicated workshop server and grants the whole cohort access by IdentiKey before Thursday's session — there is nothing to request and nothing to test tonight. You'll log in for the first time together, in the room.
