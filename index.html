Why this order

The Arc — skills that stack

The sequence is the argument: you can't use GitHub without a shell, you can't write real code without version control, and none of it is worth anything until you can tell whether the result is real. Each session's output is the next session's prerequisite, and all three land in one repo — zfp36l2-analysis.

The sessions

Three workshops, three friction points killed

Every session is built around the specific place new grad students historically get stuck — and removes it while instructors are in the room. Tap a card's button to open its hands-on page.

Bash & SSH / Cluster Computing

Friction it kills

"I've never touched a terminal, and the cluster is a black box."

You'll walk out able to

  • Log into vieques.int.colorado.edu from any laptop
  • Navigate and manage files fluently in bash
  • Know where files live — home vs. scratch vs. projects — and why it matters

Python & Reading the Data

Fri Aug 14 · 2:15 – 3:30 PM · JSCBB A400

Friction it kills

"I can assemble the code — but I can't tell whether the result is real or just noise."
